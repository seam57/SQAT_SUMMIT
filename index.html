About the summit

Where testers, builders and prompt engineers meet.

SQAT Summit brings software engineering students together for one day of live competition around automated quality assurance, secure engineering and applied generative AI. Industry judges watch the work, and the best teams get noticed.

In collaboration with

Cyber Security Club

Talent pipeline

Real-world rigor

Go past coursework: defect hunting, automated test suites and enterprise-style QA pipelines.

Generative AI

Prompt engineering, algorithmic reasoning and AI-assisted testing for how software ships today.

Across departments

Computing clubs from programming, cyber security, robotics and AI share one stage.

Logical Bug Hunting

Debugging and program logic

Every round gives you a different problem and a program that is meant to solve it. The code runs, but the answers are wrong. Find the logical bug.

When02:00 – 03:30 PM
EntryPer participant
FormatDifferent problem each round
Registration feeBDT100per participant

What gets tested

  • Reading unfamiliar code quickly
  • Spotting wrong conditions, off-by-one errors and bad loop limits
  • Proving a bug with a failing test case
ChampionBDT2,000
Runner-upBDT1,000
